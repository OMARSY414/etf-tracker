# 定投跟踪工具

一个通用的ETF/股票定投跟踪工具，支持沪深港三市。

## 功能

- 支持上海证券交易所、深圳证券交易所、香港证券交易所的所有股票
- 自动识别股票代码（sh/sz/hk前缀）
- 定投收益分析（累计投入、市值、收益率、CAGR）
- 分红再投资处理（前复权价格）
- 交互式图表（Chart.js）

## 使用方法

1. 打开 `index.html`
2. 输入股票代码（如 `513050`、`00700`）
3. 选择开始和截止日期
4. 输入每日定投金额
5. 点击"生成定投分析"

## 部署

### GitHub Pages部署

1. 在GitHub创建新仓库
2. 上传 `index.html` 文件
3. 在仓库设置中启用GitHub Pages
4. 选择main分支，根目录
5. 访问 `https://你的用户名.github.io/仓库名/`

## 技术栈

- HTML/CSS/JavaScript
- Chart.js（图表）
- 腾讯财经API（数据源）
- CORS代理（解决跨域）
